# 项目状态与任务清单 (Status)

> 启动时先读取「当前状态」；按照当前任务编号按需读取下方对应条目，以及 spec.md、plan.md 或 history.md 的相关段落。不要每次全文读取所有文件。
> 本文件是状态摘要和任务清单；需求与设计的权威来源分别为 spec.md 和 plan.md，历史事实在 history.md。摘要缺失、过期或冲突时回源核对，不以摘要覆盖原文或代码。

## 任务清单

> Phase 3 基于已确认的 plan.md 按项目实际拆解；用户确认后按顺序执行，不跳依赖。每项应可独立验证，覆盖 Fxx/Exx 或注明基础设施。
> `[ ]` 包括未开始、进行中与已实现待验收；行内状态须明确区分。仅用户确认验收后标记 `[x]`。任务状态变更时同步更新「当前状态」。

格式：

```text
- [ ] T0XX: [任务名] | 状态: 未开始/进行中/已实现待验收 | 依赖: [T0XX或无] | 涉及文件: [路径] | 验收: [可验证标准] | 覆盖: [Fxx/Exx 或 无（基础设施）]
```

（尚未拆解）

## 覆盖检查

- [ ] 每条 Fxx 至少由一个任务覆盖
- [ ] 每条 Exx 有对应的校验或测试任务
- [ ] 每项任务覆盖需求、异常或明确属于基础设施
