# 项目历史 (History)

> 按时间追加任务进度、验证、问题、决策与变更记录，不删除、不改写已有历史。恢复项目时按任务编号、决策编号或关键词检索，不默认全文读取。
> 当前有效的需求、设计与任务状态分别以 spec.md、plan.md、status.md 为准；本文件记录过程和依据，发生冲突时结合代码、Git 与用户确认回源核对。

## 记录格式

每条记录至少包含日期、编号或主题、操作/结论、影响、验证或状态。重大决策使用 D0XX 编号，记录背景、备选方案的优势与代价、选择和理由；如取代旧决策，明确标注原编号，并在 plan.md 中更新现行结论和本记录的编号。

```text
## [T0XX / D0XX / 主题] — YYYY-MM-DD
- 操作或决策：
- 影响文件或任务：
- 验证、结果或待处理问题：
- 相关提交（如有）：
```
